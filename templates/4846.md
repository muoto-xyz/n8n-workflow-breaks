# Generate AI Videos with Google Veo3, Save to Google Drive and Upload to YouTube: where this n8n template breaks

n8n template · 155,914 views

We read this template's file before you import it and found 1 trigger connected to nothing and 1 value sent with its braces instead of the data they name. [See the template on n8n.io](https://n8n.io/workflows/4846)

## What we found

**Starts nothing**

### “Schedule Trigger” is connected to nothing, so the workflow never runs on its own: new rows in the sheet wait until someone starts it by hand.

**Fix:** Connect “Schedule Trigger” to “Get new video”, as the template's note says.

**Sent as written**

### “Update Youtube URL” writes the address with the braces still in it, so every row's link reads “https://youtu.be/{{ … }}” and opens nothing.

**Fix:** Put “=” at the start of the YOUTUBE_URL value.
